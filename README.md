
# Portfólio Pessoal — Nicoly Pietra

**Aluna:** Nicoly Pietra

## Sobre o projeto

Este projeto é um portfólio pessoal desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas do Centro Paula Souza (CPS).

O objetivo é apresentar meu perfil, minha formação, meus conhecimentos e alguns projetos desenvolvidos durante o curso.

## Tecnologias utilizadas

- HTML5: estrutura das páginas.
- CSS3: aparência e personalização do site.
- JavaScript: interatividade e animações.
- Bootstrap 5: criação de um layout responsivo.
- Bootstrap Icons: ícones utilizados no site.
- GitHub Pages: publicação do portfólio na internet.

## Seções do portfólio

- **Perfil:** apresentação pessoal e formação.
- **Projetos:** apresentação de atividades desenvolvidas.
- **Habilidades:** tecnologias e conhecimentos estudados.
- **Contato:** links para entrar em contato e acessar meu GitHub.

## Funcionalidades

- Menu de navegação entre as seções.
- Layout responsivo para computadores e celulares.
- Cards para apresentar os projetos.
- Animações durante a rolagem da página.
- Botão para voltar ao topo.

## Recurso novo adicionado

Foi adicionada uma animação de entrada dos elementos durante a rolagem da página. Também foi implementado um botão que aparece quando o visitante desce a página, permitindo voltar rapidamente ao topo.

## Como o recurso foi implementado

O JavaScript utiliza a API `IntersectionObserver` para identificar quando os elementos entram na área visível da tela. Quando isso acontece, a classe `revealed` é adicionada ao elemento.

No CSS, essa classe controla a animação de entrada por meio de transições de opacidade e movimento. O botão de voltar ao topo utiliza um evento de rolagem da página para controlar sua exibição.
